01Tokenize
text → [ t0 … tn−1 ] → integer ids

The tokenizer is the only component that touches raw text. Real tokenizers learn merges (BPE / SentencePiece) over ~50k–200k tokens; this demo splits on words and punctuation and looks ids up in a 24-word vocabulary.

02Embedding lookup
X = E[id]

Each id selects one row of the learned matrix E. No position is added here — RoPE injects position inside attention.

Tensor shape invariance

Every stage preserves the token count and returns to width d — that is what lets transformer blocks stack.

Scope: stages 01–02 are the input path (text → vectors). Stages 03–08 are the attention computation itself, ending with the output projection. A decoder-only LLM (GPT, Llama, Claude) contains only causal self-attention, repeated in every layer. Cross-attention belongs to encoder–decoder models (the original Transformer, T5), where the decoder attends to encoder outputs as a separate sub-layer — the two never run at the same time.
